Selected work

Projects that moved budgets and workflows

Delivered at Plan.Net Technest India as Data Science & Engineering Manager.

Customer segmentation model

Developed and deployed a K-Prototype unsupervised clustering model that groups website customers into 10 behavioural segments. I engineered the feature pipeline end to end with AWS Glue and PySpark to ingest, clean and transform large raw datasets from S3, then built an interactive segmentation dashboard to help optimise the website customer experience.

  • K-Prototype
  • PySpark
  • AWS Glue
  • S3
  • Plotly
  • Dash

Cost-per-order analysis

Ran a year-long cost-per-order analysis in Python across marketing channels and business models. The performance trends and optimisation opportunities it surfaced directly informed a £3M reallocation toward higher-performing channels.

  • Python
  • Marketing analytics
  • Budget optimisation

Reporting pipelines

Engineered end-to-end reporting by converting the cost-per-order Python scripts into SQL for transformation and aggregation, then surfaced the metrics in an interactive Tableau dashboard showing how £10 million of cost was distributed across every channel this year.

  • SQL
  • Python
  • Tableau

Email campaign automation

Analysed 700+ email campaigns and engineered automation solutions that improved operational efficiency by 5× and increased click-to-deliver rate (CTDR) by 2%.

  • Campaign analytics
  • Automation
